# Basant Aryal — Academic Portfolio

Academic website using HTML, CSS and JavaScript, prepared for GitHub Pages at `Basant456.github.io`.

## Local preview
Open `index.html` in a browser, or use VS Code Live Server.

## Before publishing
- Replace the BA portrait placeholder with a professional photograph.
- Review all academic text and email/LinkedIn links.
- The PDF in `assets/BasantAryal_Resume.pdf` is the provided resume, and the Resume button opens it.
- Add a DOI to the VIVA-AI publication only when officially available.

## GitHub Pages
Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the ROOT of the public `Basant456.github.io` repository. Enable Settings > Pages > Deploy from a branch > main > / (root).
